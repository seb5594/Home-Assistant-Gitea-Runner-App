# Gitea Runner

Runs the Actions workflows of your own Gitea on Home Assistant: build, test and deploy from your
repositories without a cloud service.

* Finds the Gitea app by itself and registers with a token you copy once.
* Jobs run in containers next to your apps, or directly on Home Assistant to check, change and reload
  your configuration.
* The app page shows what works, in your browser's language, and has workflows to copy.

> **Pre-release.** This is a `dev` version. Please report what you see.

Open the *Documentation* tab for setup, host mode and troubleshooting.
